Docker Compose简介
    是一个用于定义和运行多容器 Docker 应用的工具。你只需在一个 .yml 文件中配置好所有服务（容器），然后一条命令就能启动、停止、管理整个应用栈。

常用 Docker Compose 命令（假设文件名为docker-compose.yml）
    启动所有服务（-d 表示后台运行（detach 模式）。不加 -d 会在前台显示日志）
        docker-compose up -d
    查看运行状态
        docker-compose ps
    查看日志
        docker-compose logs -f          # 实时跟踪所有服务日志
        docker-compose logs -f postgres # 只看 postgres 日志
    停止所有服务
        docker-compose stop
    启动已停止的服务
        docker-compose start
    重启服务
        docker-compose restart
    停止并删除容器、网络（但保留数据卷）
        docker-compose down
    停止并删除容器、网络，同时删除数据卷（⚠️ 会清空数据库）
        docker-compose down -v
    重建某个服务并重新运行（--no-deps：不重启依赖的服务。--build：重新构建镜像）
        docker-compose up -d --no-deps --build postgres
    在运行中的容器里执行命令
        # 进入 PostgreSQL 容器并打开 psql 客户端
        docker-compose exec postgres psql -U gocook -d gocookdb
        # 或者直接执行 SQL 文件
        docker-compose exec -T postgres psql -U gocook -d gocookdb < init.sql

通过 PostgreSQL 容器执行 SQL
    docker exec -it my_postgres psql -U gocook -d gocookdb
    输入 \q 退出

通过 PostgreSQL 容器执行 SQL文件
    docker exec -i my_postgres psql -U gocook -d gocookdb < /文件/的/路径

通过 pgAdmin（Web 界面）执行sql语句
    浏览器打开 http://localhost:5050
    登录：邮箱 admin@example.com，密码 admin123
    添加服务器：
        名称任意（如 GoCook DB）
        Host: postgres（因为 pgAdmin 和 PostgreSQL 在同一个 Docker 网络中）
        Port: 5432
        用户名: gocook
        密码: gocook123
    连接后，找到数据库 gocookdb → 工具 → 查询工具，输入SQL 并执行。
